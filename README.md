# ThiagoLabs — Intelligence OS

Plataforma de IA, automação e inteligência competitiva do ecossistema ThiagoLabs.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra http://localhost:3000 para ver o resultado.

## Build

```bash
npm run build
```
